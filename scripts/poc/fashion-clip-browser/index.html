Fashion-CLIP browser-only PoC

Local files are decoded and embedded in this browser tab. No image bytes, model output, or embeddings are sent to FIT-BACK backend or Modal. The model binary is fetched directly by the browser from the configured model URL (pinned Hugging Face by default).

Select one query image and one or more candidate images.
